Y-agent v0.3.0

## 新增

### M3 角色工坊 (M3.1-M3.5)
- `src/lib/character-archive.ts` 角色档案 CRUD + 跨项目 scope + 6 张参考图附件
- 角色档案导入导出(JSON,项目内 / 全局)
- Agent 工具 `character_use_archive` 支持上下文自动注入
- 4 个角色类 Skill(`character-sheet` / `character-turnaround` / `expression-grid` / `character-consistency-set`),支持 `{{character_archive}}` 占位符

### M3.6 角色工坊优化
- Workshop 受控组件化 + Editor savingStatus chip + 切档案 flushPending
- Picker projectId 真实化(按项目过滤)
- Tauri IPC `CharacterArchiveRow` 自定义 Serialize 修 `tags_json` 字段名错配
- ErrorBoundary 兜底

### P0+P1 质量完善期 (20 commits)
- 前端 i18n 基础包 (zh-CN + en-US,自实现无第三方依赖)
- 组件单测框架 + Toast / Sidebar / BoardToolbar / CommandPalette 共 21 个新用例
- 2 个新 Skill 模板:`animation-storyboard`(4-6 格动画分镜)+ `equipment-icon`(6-12 个装备图标)
- `AgentContext.usageStats` 字段(前端先行,17 用例覆盖)
- `llm-stream.ts` W1 接口冻结
- CI 闸升级:加 `gitleaks` secret scan + `pnpm audit` + `cargo deny` + `clippy` + `rustfmt`

### UI/UX 整体抛光 (节奏 / 表面 / 动效 / 空态)
- 4 套主题配色保持不变
- 新增 Motion 系统:`--dur-fast/base/slow` 时长 token、`.anim-fade-in/up/down/slide-right`、`.anim-press / anim-hover-pop / anim-pulse-soft / anim-caret / anim-bounce-in / anim-marquee` 工具类、`stagger` 入场
- 新增 elevation:`elev-sm/md/lg/xl` + `modal-backdrop` 沉浸背景
- 新增通用组件 `EmptyState`(6 种 illustration)与 `Skeleton`(shimmer + 4 种预设)
- Sidebar / Header / Tabs / PromptBar / AssetCard / ChatMessageList / AssetDetailDialog / SkillCenter / CharacterWorkshop / ProjectsPage / AssetCenter / Settings / CommandPalette / Toast 全部精修
- App.tsx 路由切换 fade
- F14 focus-visible 全局启用

## 重构

- **合并双层导航**:ProjectTabs(顶)+ ModeSwitch(底)合并成 6 项单层导航(对话 / 生图 / 生视频 / 资产 / 角色 / 工具),`tab` 作为单一状态源,删除 `inputMode` state 与 sync useEffect,删除 `ModeSwitch.tsx`
- **cargo 路径修复**:`dev-with-msvc.cmd` / `build-with-msvc.cmd` 把硬编码的 `C:\Users\17123\.cargo\bin` 改成 `%USERPROFILE%\.cargo\bin`,跨机器可移植
