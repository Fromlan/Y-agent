把用户描述的同一场景，在不同时段（早 / 午 / 晚 / 夜）各出一张，保持主体和构图一致，只换光影和氛围。

## 适用场景

- 美术设定集里的"时间光影对照"
- 同一关卡/地图的 4 个时段氛围图
- 概念稿"早午晚夜"4 联图

## 调用方式

1. 用户输入场景描述（例："一个日式庭院的角落，有石灯笼和青苔"）
2. Y-agent 自动用 5.0 Lite 组图（`max_images: 4`）
3. prompt 强调"同一构图、同一相机角度、同一主体，只改光影和氛围"
4. 输出 4 张图：早（暖金光）/ 午（顶光硬影）/ 晚（金红斜光）/ 夜（蓝紫冷光 + 灯源）

## 关键 prompt 模板

```
{{user_scene}}，同一构图、同一相机角度、同一主体，分别表现：
- 早晨：暖金色斜侧光、柔雾、长投影
- 正午：顶部硬白光、清晰短影、对比度强
- 傍晚：橙红斜长光、暖色调、柔光
- 夜晚：蓝紫冷光、灯源/月光局部高光、整体偏暗
```

## 注意

- 用 5.0 Lite（支持组图 + 流式）
- size 推荐 2k，4k 也行但慢
- 如果场景里有人物，人物姿态/位置应保持一致
- 不支持 5.0 Pro（5.0 Pro 不支持 `sequential_image_generation`）

## Seedream 提示词结构

按官方指南写 prompt（一段连贯自然语言，不要堆词）：

1. **主体 + 行为 + 环境**：明确"同一场景"——构图/相机角度/主体完全一致，只换光影和氛围
2. **风格 + 色彩 + 光影**：1-3 个关键词（写实 / 二次元 / 卡通）+ 早午晚夜具体光描述（暖金斜光 / 顶光硬影 / 橙红斜长光 / 蓝紫冷光）
3. **明确应用场景**："用作美术设定集的时间光影对照 / 同一关卡的 4 个时段氛围图 / 概念稿早午晚夜 4 联图"
4. **不需要文字**
5. **多图参考时**只此一个场景，不需要"图一"指代
6. **多图输出用"系列 4 张"触发**："系列 4 张,早/午/晚/夜各一张,场景一致,光影不同"

反面：堆砌华丽形容词、4 张构图/主体位置漂移。
