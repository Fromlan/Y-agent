把用户描述的同一场景，在不同时段（早 / 午 / 晚 / 夜）各出一张，保持主体和构图一致，只换光影和氛围。

## 适用场景

- 美术设定集里的"时间光影对照"
- 同一关卡/地图的 4 个时段氛围图
- 概念稿"早午晚夜"4 联图

## 调用方式

1. 用户输入场景描述（例："一个日式庭院的角落，有石灯笼和青苔"）
2. Y-agent 自动用 5.0 Lite 组图（`max_images: 4`）
3. prompt 强调"同一构图、同一相机角度、同一主体，只改光影和氛围"
4. 输出 4 张图：早（暖金光）/ 午（顶光硬影）/ 晚（金红斜光）/ 夜（蓝紫冷光 + 灯源）

## 关键 prompt 模板

```
{{user_scene}}，同一构图、同一相机角度、同一主体，分别表现：
- 早晨：暖金色斜侧光、柔雾、长投影
- 正午：顶部硬白光、清晰短影、对比度强
- 傍晚：橙红斜长光、暖色调、柔光
- 夜晚：蓝紫冷光、灯源/月光局部高光、整体偏暗
```

## 注意

- 用 5.0 Lite（支持组图 + 流式）
- size 推荐 2k，4k 也行但慢
- 如果场景里有人物，人物姿态/位置应保持一致
- 不支持 5.0 Pro（5.0 Pro 不支持 `sequential_image_generation`）
