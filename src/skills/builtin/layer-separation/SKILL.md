请把用户上传的参考图拆分为可独立编辑的图层。

## 适用场景

- 把设计稿 / 角色图 / KV 海报拆成"主体 + 背景 + 文字"等可拖拽图层
- 想把一张复杂图里的关键元素抠出来单独修改（交给 5.0 Pro 的交互编辑）
- 想保留可二次创作的源文件（拆完后各图层是带透明通道的 PNG）

## 参数

- 必传：`image`（要拆的那张图）
- 可选：`prompt`（告诉模型你想拆什么，例如"只拆人物和前景文字"）
- 模型固定：`doubao-seedream-5-0-pro-260628`（其它模型不支持图层拆分）
- `layerDecomposition: true`

## 拆完后怎么用

1. Y-agent 资产详情页会列出 1 张底图 + N 张图层
2. 点击每张图层的"眼睛"图标可隐藏/显示
3. 点击下载图标可单独导出某图层为 PNG（带透明通道）
4. 想再修改某图层：用 P3 局部编辑（bbox 标注），新结果会保留原图层
5. 想让 5.0 Pro 重新出图并保留图层结构：在 prompt 里说明"保持分层结构"

## 注意

- 图层最多 16 个（5.0 Pro 限制）
- 任一图层生成失败 → 整次请求失败，不支持部分成功
- 拆出来的图层都是带透明通道的 PNG
- 拆完后底图 = 原图本身，图层 = 抠出的元素（可叠加在底图上还原）
