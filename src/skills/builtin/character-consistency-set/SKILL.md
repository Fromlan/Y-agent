上传 1 张角色参考图，生成 4 张该角色不同动作 / 表情 / 视角的图，保持外观、服饰、五官高度一致。

## 适用场景

- 角色设定集（站 / 走 / 跑 / 战斗 4 个动作）
- 表情包准备（喜 / 怒 / 哀 / 乐 4 个表情）
- 同角色不同视角（正 / 侧 / 背 / 俯视）

## 调用方式

1. 用户上传 1 张参考图（必传）
2. 用户描述场景 / 动作 / 表情（例："分别是：站立、奔跑、坐姿、挥手"）
3. Y-agent 用 5.0 Lite 多图生组图（参考图 + 4 张输出）
4. prompt 强调"保持参考图角色的外观、服饰、五官、风格不变"

## 关键 prompt 模板

```
{{user_actions}}，保持与参考图完全一致的角色外观（脸型、发型、服装、配饰、画风），
只改变动作 / 表情 / 视角。同一画风与色彩基调。
```

## 注意

- 必传 `image`（参考图）
- 用 5.0 Lite（支持多图输入 + 组图）
- size 推荐 2k（4k 也行但慢）
- 4 张里如果某张"不像"，可以单张用局部编辑（bbox）修正
- 复杂动作（跳跃、战斗）容易崩坏，可拆成两次任务（先 2 张简单 + 再 2 张复杂）
