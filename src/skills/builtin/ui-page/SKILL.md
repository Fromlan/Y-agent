根据用户给的页面类型和需求，生成一张完整的游戏 UI 单页视觉稿。

## 适用页面类型（用户必须指定一种）

| 页面类型 | 用户说法示例 |
|---|---|
| 首页 / 主界面 | "首页"、"主界面"、"lobby" |
| 背包 / 道具 | "背包页"、"道具页"、"inventory" |
| 商城 / 商店 | "商城页"、"商店页"、"shop" |
| 任务 / 委托 | "任务页"、"委托页"、"quest" |
| 角色 / 详情 | "角色页"、"详情页"、"character" |
| 战斗结算 | "结算页"、"victory"、"战斗结束" |
| 排行 | "排行榜"、"leaderboard" |
| 活动 | "活动页"、"event" |

未指定时默认按"首页"生成。

## 调用方式

1. 用户说"`<UI页> <页面类型> <补充要求>`"，例：`/UI页 商城页 国风 RPG 6 宫格商品列表`
2. 用户可选上传参考图（风格参考、品牌色）
3. Y-agent 用 5.0 Pro（擅长长 prompt + UI 排版）
4. prompt 明确每个区块的相对位置 + 文字策略

## 关键 prompt 模板

```
{{user_input}}（{{page_type}} 页面），专业游戏 UI 视觉稿：

## 画面比例与基础
- 比例：{{aspect_ratio}}（默认 9:16 竖屏，商城类用 16:9）
- 平台：{{platform}}（默认手机竖屏，可选 PC 端 16:9）

## 顶部状态区
- 顶部 1 行：时间、电量、网络、玩家头像、货币栏（金币/钻石/体力）
- 不可被主内容遮挡

## 中部主内容区（按页面类型变化）
- 首页：左侧主角色立绘 + 右侧功能入口网格（任务/活动/战斗/背包/角色）
- 商城：顶部 banner + 商品宫格（3 列 × 多行） + 底部购买确认按钮
- 背包：左侧分类侧边栏 + 右侧道具网格 + 右上角搜索框
- 任务：左侧任务列表 + 右侧详情面板 + 底部"前往"按钮
- 角色：左侧角色立绘 + 右侧属性面板 + 底部装备槽
- 结算：中央大数字 + 星级评分 + 奖励列表 + 底部"再来一次 / 退出"
- 排行：顶部 tab 切换 + 排行列表（前 3 名高亮）
- 活动：顶部 banner + 活动规则 + 参与按钮 + 倒计时

## 底部导航区
- 4-5 个主功能 tab（如：首页/背包/角色/任务/商城）

## 悬浮 / 浮层
- 主操作按钮（CTA）：右下角大圆按钮或底部居中长按钮
- 资源状态栏：左下角小图标（金币数 / 体力数 / 红点提示）

## 视觉约束
- 同一画风、同一描边、同一圆角等级
- 主色 / 辅色 / 警告色统一
- 按钮有 3D 质感 + 真实点击感
- 图标尺寸统一
- 中文 / 数字 / 字母可读
- 后期排字区域预留（不放最终文字，用纯色块占位）
```

## 状态机

- 默认态（已批准 / draft）
- 加载中（占位骨架）
- 数据为空（空状态文案 + 引导按钮）
- 网络错误（错误图标 + 重试按钮）
- 资源不足（金币/体力不足时按钮置灰 + 提示"前往充值"）

## 输出要求

- 1 张 16:9 或 9:16 单图
- 默认 5.0 Pro（`doubao-seedream-5-0-pro-260628`），擅长长 prompt + 排版
- 文字可读或显式标注"后期排字"
- 主操作 / 次操作 / 信息层级清晰

## Seedream 提示词结构

按官方指南写 prompt（一段连贯自然语言，不要堆词）：

1. **主体 + 行为 + 环境**：明确"游戏 [页面类型] 单页 UI 视觉稿"——8 种页面类型之一（首页/背包/商城/任务/角色/结算/排行/活动）
2. **风格 + 色彩 + 光影**：1-3 个关键词，**默认"游戏 UI 截图风格"**——写实/二次元/美卡/卡通，1-3 个画风词
3. **明确应用场景**："用作游戏 UI 截图基准，给开发作为视觉参考"
4. **如果图上需要文字内容**（如按钮文案），把文字放**双引号**
5. **后期排字区域预留**——不放最终文字，用纯色块占位
6. **单图输出**，不需要"图一"指代或"一系列"触发词

反面：堆砌华丽形容词、把游戏 UI 当成普通插画（缺信息层级）。
