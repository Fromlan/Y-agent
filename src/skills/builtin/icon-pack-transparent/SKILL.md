请生成 6-9 个统一风格的 UI 图标，**输出 PNG 透明背景**（5.0 Pro 专属）。

## 适用场景

- 游戏的 HUD / 菜单按钮 / 道具栏
- 应用 UI 的 icon set
- 任何需要"去背直接合成"的图标合集

## 关键约束

- **必须用 5.0 Pro**（`doubao-seedream-5-0-pro-260628`），透明背景仅它支持
- **PNG 输出** + `background=transparent`（Y-agent 自动设置）
- 图标在 1 张图上**水平或网格排列**，间距均匀
- 同一画风、同一描边粗细、同一配色基调
- 单图标外缘到图边至少 8% 留白，便于裁切
- 透明区域**不能有任何白底/灰底/网格**——PS 看 alpha 通道应完全透明

## 推荐输入示例

- "RPG 游戏的 6 个核心技能图标：火球 / 治疗 / 护盾 / 隐身 / 闪现 / 大招"
- "App 设置页 8 个图标：通知 / 隐私 / 主题 / 语言 / 账号 / 关于 / 反馈 / 退出"
- "消消乐的 6 个道具：锤子 / 炸弹 / 交换 / 加步数 / 提示 / 彩虹"

## 资产角标

生成完成后，资产卡左上角会显示「透明」绿色徽章，便于筛选。

## 不适用

- 4.5/4.0 模型（不支持透明背景，会报"仅 5.0 Pro 支持"）
- 单图标（`group_count: 1` 是必须的，单图不支持图标合集概念）
- 复杂艺术风格（透明背景会让细节丢失，建议先有底色版再抠）

## 调试

- 看到图但 alpha 通道不透明 → 模型不一定是 5.0 Pro，确认 PromptBar 模型下拉
- 报 "background=transparent 仅 5.0 Pro 支持" → 切到 5.0 Pro
- 报 "output_format=jpeg 与 transparent 互斥" → 不要手选 JPEG

## Seedream 提示词结构

按官方指南写 prompt（一段连贯自然语言，不要堆词）：

1. **主体 + 行为 + 环境**：明确"6-9 个统一风格的 UI 图标合集"——是 HUD / 菜单 / 道具栏用的透明背景图标
2. **风格 + 色彩 + 光影**：1-3 个关键词（等距 / 扁平 / 写实 / 像素 / 描边线稿）——同一画风、同一描边粗细、同一阴影方向、同一配色基调
3. **明确应用场景**："用作游戏 UI 图标去背合成,直接合成到 UI"
4. **不需要文字 / 数字 / 字母**
5. **单图水平或网格排列**，间距均匀
6. **单图输出**，不需要"一系列"触发词

反面：堆砌华丽形容词、混用不同画风。
