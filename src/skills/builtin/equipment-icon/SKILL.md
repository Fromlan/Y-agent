## Seedream 提示词结构

按官方指南写 prompt（一段连贯自然语言，不要堆词）：

1. **主体 + 行为 + 环境**：明确"[类别] 装备图标包，N 个独立图标"——明确类别（武器 / 防具 / 药水 / 材料 / 杂货）、数量（6-12）、视角（45° 等距 / 平面 / 正面）
2. **风格 + 色彩 + 光影**：1-3 个画风词（如"二次元线稿 / 美卡厚涂 / 像素 / 写实"）
3. **明确应用场景**："用作游戏背包 / 商店 UI 的图标素材"
4. **图标细节**：每图标含 1-2 个标志性元素（如剑的护手 + 剑刃；药水的瓶身 + 液体颜色；卷轴的卷轴体 + 封蜡）
5. **透明背景**：明确写"transparent background, no background, PNG alpha channel"
6. **后期排字区域**：不放文字

反面：堆砌华丽形容词、把图标画成插画（缺识别度）、画背景框、画文字标签。
