请生成一个游戏关卡场景的气氛概念图，要求：

- 画面分为上中下三段（或左中右三栏），展示同一场景的：
  - 远景：环境大关系，天空、远山、城市轮廓
  - 中景：玩家主要活动的空间
  - 近景：可交互的细节，道具、纹理、视觉锚点
- 统一的光照方向、统一的色温
- 包含可识别的时间氛围（日出 / 正午 / 黄昏 / 夜晚 / 雨夜等）
- 场景描述：{{user_input}}
- 游戏类型（RPG / FPS / 平台跳跃）会影响构图重心

输出要求：作为关卡美术的 mood reference 基准，团队据此推进具体场景资产。

## Seedream 提示词结构

按官方指南写 prompt（一段连贯自然语言，不要堆词）：

1. **主体 + 行为 + 环境**：明确"关卡场景 + 远/中/近景三段 + 时段（日出/正午/黄昏/夜晚/雨夜）"——是 mood reference
2. **风格 + 色彩 + 光影**：1-3 个关键词（写实 / 二次元 / 卡通 / 像素）+ 明确"暖金斜光"或"顶光硬影"等具体光描述
3. **明确应用场景**："用作关卡美术的 mood reference 基准，团队据此推进具体场景资产"
4. **不需要文字**
5. **单图横/竖三段**（上中下 或 左中右），不需要"图一"指代
6. **单图输出**，不需要"一系列"触发词

反面：堆砌华丽形容词、远中近三段同质化、没有"时间氛围"。
