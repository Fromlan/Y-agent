请生成一张动画分镜图，要求：

- 同一角色、同一画风、同一场景
- 在一张图上包含 4-6 个连续关键帧（从左到右、从上到下排列）
- 每格标注时间码（如 `0.0s / 0.2s / 0.4s / 0.6s / 0.8s / 1.0s`）
- 动作流畅，关键帧之间有视觉连续性
- 背景简洁，不干扰主体
- 角色描述：{{user_input}}
- 角色档案约束：{{character_archive}}

输出要求：作为动画预览 / 关键帧参考使用，便于动画师对齐节奏。

## Seedream 提示词结构

按官方指南写 prompt（一段连贯自然语言，不要堆词）：

1. **主体 + 行为 + 环境**：明确"[主体]的 [动作] 关键帧分镜图，N 个连续关键帧"——明确主体（角色 / 物体 / 镜头）、动作（走 / 跑 / 跳 / 攻击 / 表情变化）、场景
2. **风格 + 色彩 + 光影**：1-3 个画风词（如"二次元线稿 / 美卡厚涂 / 写实草图"）
3. **明确应用场景**："用作动画分镜参考，给动画师对齐节奏"
4. **关键帧布局**：左到右 / 上到下，N 宫格，明确"格数"和"时间码间隔"
5. **后期排字区域**：每格小区域写时间码（用模板里要求的格式），不放其他文字
6. **连贯性约束**：动作在关键帧间必须自然过渡，不能出现姿势突变

反面：堆砌华丽形容词、把分镜当普通插画（缺时间维度）、时间码格式不统一。

## 反向限制

- 中文 / 英文乱码，错误文字，莫名符号
- 商标 / 知名 IP 角色 / 受版权保护的形象
- 时间码格式必须为 `0.0s` 风格（不能用 `0:00` 或纯数字）
- 关键帧之间角色动作必须连贯，不能出现姿势突变
- 不可出现多个角色混在一格
- 背景不可干扰主体
