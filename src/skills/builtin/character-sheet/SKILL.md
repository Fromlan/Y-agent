请生成一个游戏角色的完整设定卡，要求：

- 同一角色、同一画风
- 在同一张图上包含 4 个区块：
  1. 左上：全身正面（站姿）
  2. 右上：半身特写（突出面部和服饰细节）
  3. 左下：表情 4 宫格（中性 / 战斗 / 喜悦 / 沉思）
  4. 右下：角色标志性道具或武器
- 背景使用柔和的渐变色或纯色，避免干扰
- 角色描述：{{user_input}}
- 包含角色世界观（如"赛博朋克侦探" / "仙侠剑客"）会自动补充设定细节

输出要求：作为角色概念设定稿使用，便于文案、美术、策划三方对齐角色形象。

## Seedream 提示词结构

按官方指南写 prompt（一段连贯自然语言，不要堆词）：

1. **主体 + 行为 + 环境**：明确"谁在做什么"——这里是游戏角色身份 + 4 宫格区块分布
2. **风格 + 色彩 + 光影**：1-3 个关键词，**默认二次元**（除非用户明确写"写实"/"美卡"/"3D 厚涂"）
3. **明确应用场景**："用作游戏角色设定卡，给文案/美术/策划三方对齐"
4. **如生成文字内容**（如角色名），把文字放**双引号**
5. **多图参考时**用"图一"指代参考图
6. **单图输出**，不需要"一系列"触发词

反面：堆砌华丽形容词、复述用户原话而不扩展、风格词与画面矛盾。
